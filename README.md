# BW Food Consulting — landing pages dla 1026 miast

Niezależny od Landingi generator statycznych stron lokalnych dla domeny `lp.technologzywnosci.pl`.

Źródłem listy miast jest oficjalny wykaz jednostek KTS GUS według stanu na 1 stycznia 2026 r. Generator wybiera:

- gminy miejskie,
- części miejskie gmin miejsko-wiejskich.

Oczekiwana liczba stron miejskich: **1026**.

Repozytorium jest przygotowywane etapami. Publikacja na domenie produkcyjnej nastąpi dopiero po walidacji treści, adresów URL, przekierowań i sitemap.
